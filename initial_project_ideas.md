
# Capstone Project Ideas

### Trade-bay

- Use the ebay API to get info on items and users
- Add a wanted items list for each user
- If two users have matching items on their wanted list, notify them so they can initiate a trade
- Have an initiate trade with user feature, where a user can ask to trade with a specific user for a specific product.

***

### SavEnergy	

- Use the Unplugg API to forecast energy usage of appliances.
- If the energy usage is too much, make some adjustments.
- Allow users to adjust their desired levels of energy usage for a timeframe.

***

### MovieCriticCritics

- Use the Omdb API to get info on movies like average rating from critics.
- Users can write critiques with ratings of a movie and add it to the database. These ratings will affect the average rating of the movie.
- People can either upvote or downvote the critique. They can add comments to the critique.
- If enough people downvote the critique, it disappears from the movie’s record and average rating acts is calculated anew.
